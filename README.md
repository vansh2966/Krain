# Krain

this project is one the most complex project i am going to make, i mean it looks simple, but it isnt, this just 1st version of it. i have a lot of ideas in my for upcomming version. after completing v1 and finding out my problems, things that cause issue. and overall it is good enough for v2. i wanted to make this project for desk to show time and cool images or artifacts. with sound, i can play little background music too. i few ideas to add some games in it. it rotate horizontal or vertical depending on ur need. 


**assembly guide**
1) attach all components to its place with screws
2) wire them up according wiring diagram
3) complete assembly with screws
4) upload the code ( u can use micro sd card to upload the code in raspberry pi (reccommed, cuz u can store iamges for wallpaper))
5) and its ready to use
